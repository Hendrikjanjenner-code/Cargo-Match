description: Approved narration and pacing priorities for CargoMatch promotional film revisions.
---

Use the approved original Irish library narration direction and speech-led editing
for CargoMatch films. Natural rhythm takes priority over retaining the original
film's runtime; preserve meaningful content, not empty pauses.

**Why:** The user approved an audible/visual sample with this narrator and softer
transitions, then explicitly authorized a shorter full film if that feels more
natural. The original reference to a celebrity voice did not become a request
to clone that person; an original library voice was accepted instead.

**How to apply:** Keep narration continuous through picture transitions where
appropriate. Do not return to isolated fixed-length narration slots or fill
time with silence merely to reproduce the original duration. Preserve the
previous full export when making revised versions. Ask before materially
changing the approved voice direction.
