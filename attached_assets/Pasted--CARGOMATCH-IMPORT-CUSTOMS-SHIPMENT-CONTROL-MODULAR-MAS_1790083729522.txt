# CARGOMATCH — IMPORT, CUSTOMS & SHIPMENT CONTROL

## MODULAR MASTER EXTENSION PROMPT

Extend the existing CargoMatch application with a new modular product family for international import shipments.

IMPORTANT:

Do NOT rebuild the existing CargoMatch application.

Do NOT remove or break:

* existing inland-waterway functionality
* deepsea functionality
* road
* rail
* air cargo
* capacity matching
* cargo matching
* expected availability
* maps
* companies
* users
* permissions
* networks
* messages
* demo users
* existing CargoMatch design system.

This is an EXTENSION of the existing CargoMatch platform.

The new functionality must be built as SEPARATE ACTIVATABLE MODULES.
