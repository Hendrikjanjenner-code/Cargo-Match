# CARGOMATCH — SIDEBAR, DEMO USERS & ROLE-BASED UX EXTENSION V2

Extend the EXISTING CargoMatch application.

IMPORTANT:

Do NOT rebuild the application from scratch.

Do NOT remove or break existing CargoMatch functionality.

This prompt builds on the existing CargoMatch Master Specification and the Deepsea + Multimodal Master Extension.

The objective is to create:

1. A professional persistent LEFT SIDEBAR
2. ROLE-AWARE navigation
3. TRANSPORT-MODE-AWARE navigation
4. Multiple DEMO USERS
5. Multiple DEMO COMPANIES
6. Secure DEMO USER SWITCHING
7. ROLE-SPECIFIC dashboards
8. Cross-persona demo scenarios
9. A clear distinction between company roles, operational profiles and security permissions
10. A demo environment suitable for testing and presenting CargoMatch

CargoMatch must no longer behave as if Andy Kers is the only user.

The application must be demonstrable from BOTH SIDES of the marketplace.

---

# 1. CORE UX PRINCIPLE

CargoMatch is one platform with multiple perspectives.

The application must adapt to:

WHO IS LOGGED IN

*

WHICH COMPANY THEY REPRESENT

*

WHICH TRANSPORT MODE THEY WORK IN

*

WHICH OPERATIONAL PROFILE THEY HAVE

*

WHAT THEY ARE AUTHORIZED TO DO

Do not give every user the same dashboard.

Do not give every user the same navigation.

Do not confuse operational profile with security permissions.
